==================================================
GLOBAL MOTION SYSTEM
==================================================

Create ONE unified animation system across the entire application.

Animations must feel:

- Smooth
- Premium
- Fast
- Natural
- Physical
- Responsive
- Intentional

Target 60 FPS.

Never animate everything at once.

The user should feel:

"This app responds beautifully."

Not:

"This app is full of animations."

Use consistent easing and timing throughout the app.

Preferred transitions:

- 250–400ms for normal UI transitions
- 400–700ms for premium hero transitions
- Spring physics for interactive controls
- Very subtle parallax
- Opacity + translateY for content reveals
- Scale only when useful

Avoid long animations that delay usability.
